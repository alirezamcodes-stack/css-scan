# Changelog

## 0.2.0 — 2026-09-25

- Added cascade diagnostics with selector specificity, source order, and cautious candidate/overridden/inactive/unknown statuses.
- Preserved CSS drafts across settings updates and kept focused visual edits intact during viewport resize.
- Rejected CSS edits without valid declarations and documented inline-property removals in CSS change export.
- Improved inspector scrolling on short viewports and expanded Chrome integration checks.

## 0.1.0 — 2026-09-25

- Added an on-demand Manifest V3 Chrome extension with a local CSS inspector.
- Added CSSOM matched rules, computed fallback, pseudo-elements, media queries, CSS variables, and component export.
- Added live code and visual editing, DOM navigation, tokens, change history, undo, and CSS/JSON export.
- Added popup, settings, icons, offline packaging, engine tests, and a Google Chrome for Testing integration smoke test.
